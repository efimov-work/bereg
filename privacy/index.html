Обработка персональных данных

Подготовка сайта к запуску. Формы по умолчанию работают в демонстрационном режиме. Данные не отправляются на сервер и не сохраняются в браузере.

Перед включением заявок

Владелец сайта должен заменить эту страницу утверждённой политикой. Указать оператора, контакты, цели, состав и сроки обработки, получателей данных и порядок обращения по вопросам персональных данных.

Технические данные

Шрифты и медиа загружаются с сайта. Хостинг может вести технические журналы запросов. Яндекс.Метрика включается только при настройке владельцем. Её использование должно быть отражено в опубликованной политике.
