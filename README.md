# Берег

Сайт риэлтора для подбора недвижимости у моря. Тексты и формы обращены к покупателю. Стек и структура повторяют Acter, Mercato и PolyanaPik: Next.js 16.3.5, React 19.3.0, TypeScript 5.9.3, App Router, CSS без UI-библиотек.

Медиа показывают вымышленную концепцию комплекса. Это примеры желаемой среды, а не каталог доступных объектов. Цены, адреса и контакты не выдуманы.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Сайт: http://localhost:3000. Шрифты Manrope и Prata загружаются локально через `next/font/local`. Внешние CDN не нужны.

```bash
npm run typecheck
npm run build
npm start
```

`npm start` запускает локальную проверку сборки. Для размещения предусмотрен standalone-контейнер.

## Настройки

Локально используйте `.env.local`. Для Docker Compose и скрипта Telegram используйте `.env`. Образец: `.env.example`. Секреты не попадают в репозиторий и клиентский JavaScript.

| Переменная | Когда применяется | Назначение |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | сборка | основной домен с протоколом |
| `SITE_NOINDEX` | сборка | `1` закрывает сайт от индексации |
| `NEXT_PUBLIC_BASE_PATH` | статический экспорт | подпапка, например `/bereg` |
| `YANDEX_VERIFICATION` | сборка | код Яндекс.Вебмастера |
| `GOOGLE_SITE_VERIFICATION` | сборка | код Search Console |
| `NEXT_PUBLIC_YM_ID` | сборка | номер Яндекс.Метрики |
| `NEXT_PUBLIC_LEADS_ENABLED` | сборка | `1` включает отправку формы |
| `LEADS_ENABLED` | запуск | `1` включает серверный приём заявок |
| `TELEGRAM_BOT_TOKEN` | запуск | токен бота |
| `TELEGRAM_CHAT_ID` | запуск | получатель заявок |
| `TELEGRAM_THREAD_ID` | запуск | тема группы, если нужна |
| `TRUST_PROXY` | запуск | `1` включает лимит по IP за доверенным прокси |
| `LEADS_DATA_DIR` | запуск | каталог журналов заявок |
| `WEB_PORT` | Docker Compose | внешний порт, по умолчанию `3000` |

Контакты риэлтора задаются в `src/lib/content.ts`, объект `CONTACTS`. Пустые реквизиты и мессенджеры скрыты. После заполнения телефона кнопка шапки открывает звонок через `tel:`. До заполнения она ведёт к контактной форме.

Публичные настройки, домен и контакты требуют новой сборки. Telegram и каталог заявок читаются при запуске.

## SEO

Единый конфиг: `src/lib/seo.ts`. Метаданные используют [Metadata API Next.js](https://nextjs.org/docs/app/getting-started/metadata-and-og-images).

Подготовлены:

- `title`, `description`, `canonical`, Open Graph и Twitter Card;
- JSON-LD с `WebSite`, `WebPage`, `RealEstateAgent` и `Service`;
- `robots.txt` с блоком Яндекса и очисткой рекламных параметров;
- `sitemap.xml` с изображениями и датой сборки;
- локальная иконка и `manifest.webmanifest`;
- коды подтверждения прав в вебмастерах;
- редирект с `www` и защитные HTTP-заголовки в серверной версии;
- Яндекс.Метрика и цели `lead`, `phone`, если настроен счётчик.

В микроразметке нет вымышленных адресов, координат, цен и доступных лотов. Контакты берутся из того же объекта, что отображается на странице. Превью ссылок использует готовый постер 1280 × 712.

По умолчанию индексация закрыта. Без домена canonical указывает на `http://localhost:3000`, а `NOINDEX` остаётся включён. Для запуска задайте домен и `SITE_NOINDEX=0`, затем пересоберите сайт. Политика остаётся `noindex` до замены черновика.

## Формы и Telegram

По умолчанию обе формы демонстрационные. Контактные данные не отправляются и не сохраняются. Клиент показывает результат проверки, а `/api/lead` возвращает `503 not_configured`.

Для рабочего приёма заявок:

1. Заполнить контакты в `src/lib/content.ts`.
2. Заменить заготовку `/privacy/` утверждённой политикой владельца сайта.
3. Настроить получателя Telegram и постоянное хранение журнала.
4. Установить `NEXT_PUBLIC_LEADS_ENABLED=1` и `LEADS_ENABLED=1`.
5. Пересобрать и проверить сайт.

В заявке передаются имя, телефон, бюджет, пожелания и контекст кнопки. Сервер проверяет поля и согласие. Скрытое поле отсекает ботов. Есть ограничение размера тела запроса и частоты обращений.

Заявка сохраняется в `leads.jsonl` до отправки в Telegram. При недоступной доставке она также записывается в `leads-undelivered.jsonl`. Ошибка основного хранилища возвращает `503`, чтобы форма не сообщала об успешном приёме.

Лимиты: три заявки с номера в час, десять с IP в час при `TRUST_PROXY=1`, 120 заявок в минуту суммарно. Для нескольких серверных экземпляров файловое хранилище и лимиты нужно заменить общими.

Скрипт настройки Telegram повторяет соседние проекты:

```bash
npm run tg chats
npm run tg test
```

Первая команда получает идентификаторы чатов. Вторая отправляет пробное сообщение получателю из `.env`.

## Docker

```bash

```

Образ использует Node.js 22 и `output: standalone`. Журнал хранится в томе `leads-data`. Смена настроек сборки требует `docker compose up --build -d`.

## Статическое превью и GitHub Pages

```bash
npm run export
```

Результат: `out/`. Сборка выполняется во временной копии. Серверный API исключается из превью, рабочая `.next` сохраняется. Формы остаются демонстрационными. Индексация, аналитика и коды вебмастеров отключены.

Для подпапки:

```bash
NEXT_PUBLIC_BASE_PATH=/bereg NEXT_PUBLIC_SITE_URL=https://example.github.io npm run export
```

Workflow `.github/workflows/pages.yml` собирает `out/` и публикует его через GitHub Actions при push в `main`. В Settings → Pages выбрать GitHub Actions. Исходники, секреты и служебные файлы в Pages-артефакт не входят.

Альтернативный сценарий соседних репозиториев:

```bash
npm run pages
```

Он публикует сборку в ветку `gh-pages`. Для него в настройках Pages нужно выбрать эту ветку. Два способа публикации не следует включать одновременно.

## Анимации и адаптивность

Заголовки появляются подъёмом из маски, тексты мягким затуханием, медиа лёгким приближением. Карточки появляются последовательно. Шапка липнет к верху и показывает прогресс чтения. Между тёмными и светлыми разделами стоят волны. Под главным экраном идёт бегущая строка услуг. Текст инфраструктуры меняется с переходом. Меню, формы, FAQ и состояния наведения анимированы.

Видео проигрываются только в видимой области. При открытии меню или диалога воспроизведение останавливается. Бассейн и спа переключаются по окончании ролика, фото ресторана и лобби показываются по шесть секунд. Пауза сохраняет оставшееся время.

Системное сокращение движения отключает анимации и загрузку видео. Экономия трафика отключает автоматическое воспроизведение и загрузку видео. Без JavaScript тексты, изображения и FAQ остаются доступны.

Убраны повторяющиеся плашки преимуществ, номера разделов, декоративные круги, лишние подписи и дублирующие пояснения. В галерее оставлена одна подпись о концептуальных визуализациях.

Проверены 24 размера от 280 до 3840 px, включая горизонтальные телефоны. Формы используют шрифт 16 px для ввода. Диалоги ограничены высотой экрана и прокручиваются. Главное видео сохраняет исходные пропорции и ширину не более 1280 px.

## Проверки

```bash
npm run typecheck
npm run build
npm run test:lead
```

`test:lead` сам запускает собранный сервер и локальную имитацию Telegram. Внешние сообщения не отправляются. Проверяются запись заявки, доставка, экранирование текста, поля, согласие, лимиты, размер запроса и чужой Origin.

HTTP-проверки сайта требуют запущенный сервер:

```bash
# В другом терминале: npm start
npm test

# Для другого адреса:
TEST_SITE_URL=http://127.0.0.1:4186 npm test
```

Проверяются серверный HTML, метаданные, JSON-LD, robots, sitemap, превью ссылок, политика и отключённый приём заявок. Для сервера с включёнными заявками используйте `TEST_LEADS_ENABLED=1`.

Браузером проверены формы и валидация, контекстные запросы, галерея, вкладки с клавиатурой, FAQ, меню, смена сцен, остановка видео, анимации и reduced motion. Скриншоты находятся в игнорируемой папке `artifacts/`.

## Медиа

Повторная подготовка роликов требует локальный ffmpeg:

